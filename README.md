# Ping Pong Score

Табло для настільного тенісу зі статистикою гравців. PWA-застосунок + бекенд на Google Apps Script.

## Українською

- Вхід у застосунок - за кодом групи, видається адміністратором.
- Повноекранне табло з підрахунком рахунку, автоматичним визначенням подачі та зміною сторін.
- Статистика: перемоги/поразки, вінрейт, серії, head-to-head, історія матчів.
- Працює офлайн: незбережені матчі чекають у черзі й відправляються при появі інтернету.
- Теми світла/темна/системна з динамічною кольоровою палітрою.

## English

A scoreboard app for table tennis with player statistics. PWA frontend + a Google Apps Script backend.

- Sign in with a group join code, issued by an admin.
- Fullscreen scoreboard with score tracking, automatic serve indicator, and side switching between sets.
- Stats: wins/losses, win rate, streaks, head-to-head, match history.
- Works offline: unsaved matches queue locally and sync once a connection is available.
- Light/dark/system theme with a dynamically generated accent color palette.
